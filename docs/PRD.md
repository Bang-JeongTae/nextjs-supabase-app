# 모임 이벤트 관리 웹 MVP PRD

## 🎯 핵심 정보

**목적**: 수영·헬스 등 정기 소모임의 주최자가 카카오톡 대신 웹에서 공지·참여자 관리를 효율적으로 처리할 수 있도록 지원  
**사용자**: 정기 소모임(러닝크루형) 주최자 및 참여자

---

## 🚶 사용자 여정

```
┌─ 신규 사용자 (비로그인)
│  1. 로그인 페이지 진입
│     ↓ [회원가입 버튼]
│  2. 회원가입 페이지
│     ↓ [가입 완료]
│  3. 로그인 페이지 → 로그인
│     ↓ [로그인 성공]
│
├─ 기존 사용자 (로그인됨)
│  1. 내 모임 목록 페이지
│     ├─ [새 모임 만들기] → 그룹 생성 폼 → 모임 생성 → 내 모임 목록
│     ├─ [기존 모임 선택] → 그룹 홈
│     └─ [초대 링크 공유받음] → 그룹 초대 랜딩 → [가입] → 내 모임 목록
│
├─ 모임 홈 (로그인 사용자)
│  1. 그룹 홈 페이지 (공지 피드 + 다가오는 일정)
│     ├─ [공지 작성] → 공지 작성 페이지 → 공지 등록 → 그룹 홈
│     ├─ [공지 클릭] → 공지 상세 페이지
│     ├─ [일정 생성] → 일정 생성 페이지 → 일정 등록 → 그룹 홈
│     ├─ [일정 클릭] → 일정 상세 페이지 (RSVP 응답 가능)
│     └─ [멤버 관리] → 그룹 멤버 목록 페이지
│
├─ 비회원 참여자
│  1. 이벤트 공개 링크 접속 (`/e/[publicToken]`)
│     ↓
│  2. 비회원 RSVP 페이지
│     ├─ [이름 입력] → [참석/불참 선택] → [제출]
│     └─ [완료]

└─ 알림 (로그인 사용자)
   1. 새 공지/일정 등록 시 → 벨 아이콘에 알림 배지 표시
   2. [알림 아이콘 클릭] → 알림함 페이지 → 알림 목록 확인
```

## ⚡ 기능 명세

### 1. MVP 핵심 기능

| ID       | 기능명                   | 설명                                                          | MVP 필수 이유                                | 관련 페이지          |
| -------- | ------------------------ | ------------------------------------------------------------- | -------------------------------------------- | -------------------- |
| **F001** | 모임(그룹) 생성          | 이름, 카테고리, 설명을 입력해 새 모임 생성                    | 주최자가 모임을 관리하기 위한 최기초 단위    | 그룹 생성 폼         |
| **F002** | 그룹 초대 링크 생성/관리 | 회원가입 없이 그룹에 참여할 수 있는 초대 링크 공유            | 신규 멤버 확보의 핵심, 가입 장벽 제거        | 그룹 멤버 목록       |
| **F003** | 공지 작성/열람           | 주최자가 공지 작성, 모든 멤버가 열람 가능                     | 중앙 집중식 정보 전달로 메신저 대체          | 공지 작성, 공지 상세 |
| **F004** | 공지 상단 고정(핀)       | 중요 공지를 상단에 고정 표시                                  | 중요 정보의 가시성 확보                      | 공지 작성, 그룹 홈   |
| **F005** | 일정 생성                | 일정 제목, 설명, 장소, 시간, 정원, RSVP 마감 입력             | 모임 실행의 기본 단위, 참석 확인의 토대      | 일정 생성            |
| **F006** | 일정 반복 설정           | 주간 반복 옵션 (매주 같은 요일)                               | 정기 모임의 반복 작업 자동화                 | 일정 생성            |
| **F007** | 일정 상세 조회           | 일정의 전체 정보 및 참석자 목록 열람 (주최자)                 | 참석 현황 실시간 파악                        | 일정 상세            |
| **F008** | RSVP 응답 (회원)         | 로그인 사용자가 일정에 참석/불참/대기 응답                    | 참석자 관리의 핵심 기능                      | 일정 상세            |
| **F009** | RSVP 응답 (비회원)       | 로그인 없이 이벤트 공개 링크로 이름 입력 후 응답              | 친구 모임 등 낮은 진입장벽 필요              | 비회원 RSVP 페이지   |
| **F011** | 인앱 알림                | 새 공지/일정 등록 시 로그인 멤버에게 알림 발송 및 알림함 제공 | 메신저 대체의 필수 요소, 주요 정보 놓침 방지 | 알림함               |

- 고급 검색 및 필터링
- 소셜 기능 (팔로우, 좋아요 등)

## 📄 페이지별 상세 기능

### 로그인 페이지

> **구현 기능:** `F010` | **인증:** 불필요

| 항목            | 내용                                                                                                                                             |
| --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| **역할**        | 사용자 인증 진입점, 기존 사용자의 로그인 처리                                                                                                    |
| **진입 경로**   | 앱 진입 시 비로그인 상태 → 로그인 페이지 자동 이동, 또는 로그아웃 후                                                                             |
| **사용자 행동** | 이메일과 비밀번호를 입력하고 로그인 버튼 클릭                                                                                                    |
| **주요 기능**   | • 이메일 입력 필드<br>• 비밀번호 입력 필드<br>• 로그인 버튼<br>• 비밀번호 찾기 링크<br>• 회원가입 링크<br>• 유효성 검사 (이메일 형식, 필수 입력) |
| **다음 이동**   | 로그인 성공 → 내 모임 목록 페이지, 실패 → 에러 메시지 표시                                                                                       |

> **구현 기능:** `F012`, `F001` | **인증:** 로그인 필수

| 항목            | 내용                                                                                                                                                                      |
| --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **역할**        | 로그인 사용자가 가입한 모든 모임을 한눈에 확인하고 모임을 생성하는 허브                                                                                                   |
| **진입 경로**   | 로그인 성공 후 자동 진입, 로그인 사용자의 기본 페이지, 헤더 "내 모임" 메뉴 클릭                                                                                           |
| **사용자 행동** | 가입한 모임 카드를 보고, 클릭해서 그룹 홈으로 이동하거나, "새 모임 만들기" 버튼을 클릭                                                                                    |
| **주요 기능**   | • 가입한 모임 카드 목록 (이미지, 이름, 멤버 수, 다음 일정)<br>• 모임별 카드 클릭 → 그룹 홈 이동<br>• **새 모임 만들기** 버튼<br>• 모임이 없을 때 안내 메시지 및 생성 유도 |
| **다음 이동**   | 모임 카드 클릭 → 그룹 홈 페이지, "새 모임 만들기" 클릭 → 그룹 생성 폼                                                                                                     |

| **다음 이동**   | 비회원 → 로그인 페이지, 로그인 후 다시 초대 링크 접속 시 자동 가입 → 그룹 홈, 이미 가입함 → 그룹 홈                                                                                                                                         |

> **구현 기능:** `F003`, `F004`, `F005`, `F007`, `F008` | **인증:** 로그인 필수 (멤버 확인)

| **진입 경로**   | 내 모임 목록에서 모임 카드 클릭 또는 그룹 URL 직접 접속                                                                                                                                                                                                                                                                                                                                                                                                      |

| **주요 기능**   | • **공지 섹션** (상단 고정된 공지 먼저 표시)<br> - 고정 공지 (핀 표시)<br> - 일반 공지 (날짜순 내림차순)<br> - 각 공지 카드: 제목, 미리보기, 작성일시<br> - "공지 작성" 버튼 (주최자만 노출)<br>• **일정 섹션** (다가오는 순서)<br> - 다음 일정 1~3개 프리뷰<br> - 각 일정: 날짜, 제목, 참석/미응답 인원<br> - "일정 생성" 버튼 (주최자만 노출)<br>• **모임 정보 헤더**<br> - 모임 이름, 카테고리, 설명<br> - 멤버 수<br> - "멤버 관리" 버튼 (주최자만 노출) |
| **다음 이동**   | 공지 클릭 → 공지 상세 페이지, 일정 클릭 → 일정 상세 페이지, "공지 작성" → 공지 작성 페이지, "일정 생성" → 일정 생성 페이지, "멤버 관리" → 그룹 멤버 목록 페이지                                                                                                                                                                                                                                                                                              |
